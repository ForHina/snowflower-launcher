

A personal, non-commercial desktop launcher for **Minecraft: Java Edition** (Windows), built with Rust + Tauri.

## What it does
- Sign in with your own Microsoft account (device code flow) and launch the Minecraft: Java Edition copy you own
- Installs Minecraft, Fabric Loader and the required Java runtime from official sources (Mojang, FabricMC)
- Installs performance mods (Sodium, Lithium, etc.) and lets you browse mods from Modrinth
- Separate instances per Minecraft version

## Privacy
- Passwords are never asked for or stored. Login happens on Microsoft's own page.
- Tokens are stored only on the user's PC.
- Only the Minecraft profile (name, UUID) is read, to start the game.
- No offline/cracked play, no ads, not sold.

## Supported versions
Minecraft 1.21.1 – 1.21.11, 26.1 – 26.3 (Fabric)

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
